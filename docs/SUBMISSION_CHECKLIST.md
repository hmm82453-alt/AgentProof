## 5. 数据边界

当前地图、撤离条件、资源点和干员数据属于竞赛演示配置，页面和文档均标明了这一边界。
它们用于验证多 Agent 的规划、冲突发现、修改和恢复机制，不代表游戏官方实时数据。

正式提交前，如比赛指定了游戏版本，可用以下位置核对和调整：

- 地图：`backend/app/data/maps.py`
- 干员：`backend/app/data/operators.py`

调整后必须重新运行：

```powershell
cd backend
.\run-tests.ps1
python scripts/evaluate.py
```

## 6. 重新生成最终交付包

在项目根目录运行：

```powershell
.\package-release.ps1
```
