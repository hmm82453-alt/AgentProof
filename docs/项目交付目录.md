## 1. 核心交付

### 前端

- `delta-agent-console.html`：单文件比赛控制台，包含任务输入、Agent 运行过程、结果、事件记录、历史运行和移动端布局。
- `backend/app/main.py`：把上述页面作为首页提供，并连接后端 API 和 SSE。

### 后端

- `backend/app/main.py`：FastAPI 入口、REST API、SSE 事件流和前端静态页面路由。
- `backend/app/schemas.py`：请求、响应、Agent 和运行记录的数据结构。
- `backend/app/config.py`：模型、API、CORS 和运行配置。
- `backend/Dockerfile`：后端容器构建文件。
- `docker-compose.yml`：项目容器编排配置。
- `backend/requirements.txt`：后端依赖。
- `backend/start.ps1`：Windows 一键启动脚本。
- `backend/run-tests.ps1`：Windows 测试脚本。
- `backend/mcp_server.py`：MCP 服务入口。

### 五类 Agent

- `backend/app/agents/map_intel.py`：地图情报 Agent。
- `backend/app/agents/risk.py`：风险评估 Agent。
- `backend/app/agents/supply.py`：物资与负重 Agent。
- `backend/app/agents/operator.py`：干员协同 Agent。
- `backend/app/agents/audit.py`：方案校验与复盘 Agent。
- `backend/app/agents/base.py`：Agent 公共基类。

### 编排与服务层

- `backend/app/services/orchestrator.py`：多 Agent 运行、轮次推进、失败恢复和最终仲裁。
- `backend/app/services/scheduler.py`：Agent 调度。
- `backend/app/services/registry.py`：Agent 与工作流版本注册表。
- `backend/app/services/events.py`：运行事件流。
- `backend/app/services/storage.py`：SQLite 持久化、事件、快照、差异和恢复。
- `backend/app/services/llm.py`：OpenAI 兼容模型接入及失败回退。
- `backend/app/services/evaluation.py`：批量场景评测。
- `backend/app/tools/registry.py`：Agent 可调用工具及其权限注册。

### 游戏数据

- `backend/app/data/maps.py`：五张地图的撤离点、危险区、物资、路线和场景数据。
- `backend/app/data/operators.py`：干员定位、技能、负重和协同数据。

已包含地图：

- 零号大坝
- 长弓溪谷
- 巴克什
- 航天基地
- 潮汐监狱

### 数据库

- `backend/runtime/runs.db`：SQLite 运行数据库。

当前库中已有：

- 5 个 Agent 定义
- 6 个 Agent 版本
- 1 个工作流及其版本
- 17 次运行
- 830 条运行事件
- 35 个可恢复快照
